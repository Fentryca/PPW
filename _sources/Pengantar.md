# Pengantar Web Mining

Web Mining atau penambangan web merupakan suatu proses penemuan pola atau mengekstrak dari suatu web atau internet dengan menggunakan berbagai teknik penambangan data. Informasi yang sudah didapat dapat digunakan oleh perusahaan untum mengambil keputusan yang efektif. Teknik yang digunakan dalam Web Mining antara lain teknik data mining, machine learning, dan analisis statistik. 
Tujuan dari Web Mining sendiri adalah menemukan pola-pola berguna atau pengetahuan dari struktur hiperlink web, isi dari halaman web, serta perilaku pengguna.
