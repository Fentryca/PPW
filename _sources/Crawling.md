# Web Crawling

Web Crawling atau disebut dengan web scrapping merupakan proses mengambil atau mengumpulkan suatu data dari suatu halaman web. Crawling merupakan proses otomatis yang dilakukan oleh program yang dgunakan untuk menemukan informasi diseluruh internet. Dengan Crawlling kita dapat menemukan data tidak hanya berupa teks tetapijuga gambar bahkan video dari halaman web. 

Fungsi Crawling sendiri antara lain:
1. Memungkinkan konten muncul di hasil pencarian
2. Digunakan untuk menganalisis data
3. Meningkatkan visibilitas website
